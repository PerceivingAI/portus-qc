Camera Credentials
How to get the RTSP/Camera Account Username and Password:
  1. Log into the IP Camera's app.
  2. Select the camera you want to configure.
  3. Go to Settings/Advanced Settings.
  4. Turn on Camera Account and create a Username and Password (These are separate from the app's credentials).
  5. Reset your Camera.
Some cameras need to be reset aftermultiple connection attempts.
